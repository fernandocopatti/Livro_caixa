Importar

        
Traga extratos e faturas do banco ou cartão: OFX (recomendado), PDF ou planilha. O app detecta conta, evita duplicatas e lembra o mapeamento.

      


      

        
Como exportar do seu banco

        

          A melhor opção é o arquivo OFX (ou QFX): vem estruturado, com data, valor e identificação única da transação.
          Não há conexão automática com o banco neste app (sem Open Banking) — você exporta o arquivo e importa aqui.
        

        
    
          
  • Nubank / Inter / C6 / PicPay — no app, procure Extrato → Exportar / Baixar OFX ou CSV
    • 
          
  • Itaú / Bradesco / Santander / BB — internet banking → Extrato → Exportar OFX ou planilha
    • 
          
  • Cartão — fatura fechada em PDF (texto) ou CSV; se o PDF for imagem, use OFX/CSV
    • 
        

      


      

        
        
        
      


      

        

          

            
            
          

          

            Arraste um ou vários arquivos OFX / QFX
ou toque para escolher — vários extratos são mesclados na revisão
          

          

            
          

          

            Se o arquivo não aparecer na lista do celular, escolha “Todos os arquivos” / “Arquivos” e selecione o download
            (alguns bancos salvam como .txt ou sem extensão).
          

          
          

          

        


        

          

            
            
          

          

            Arraste um ou vários PDFs aqui
ou clique para escolher — pode selecionar vários arquivos de uma vez
          

          
          

        


        

          

            
            
          

          

            Arraste uma ou várias planilhas aqui
.xlsx, .xls ou .csv — vários arquivos na mesma conta; mapeamento lembrado
          

          
          

        

      

    


    
    

      

        
Categorias

        
Crie, edite ou remova as categorias usadas nos seus lançamentos. Para criar novos tipos de lançamento além de despesa/receita (ex.: Investimento), vá em Config → Tipos de lançamento.

      


      


      

        
Regras automáticas de categoria

        

          Além das palavras-chave da categoria, você pode criar regras com faixa de valor.
          Ex.: descrição contém “farmácia” e valor entre 50 e 500 → Saúde.
          
Etiqueta Manual = você cadastrou · App = aprendida na importação/correção.

Reclassificar lançamentos

Gerar palavras-chave a partir dos lançamentos

        

          Lê as categorias que você já revisou e grava palavras-chave nas categorias
          (e opcionalmente regras). Assim, numa reimportação o app já reconhece Mercado, Combustível, etc.

Google Drive

            (tipo “Aplicativo da Web”). Ative também a Google Drive API. Em origens JavaScript autorizadas, use a URL HTTPS do app.

Backup completo

          

            A planilha é ótima pro dia a dia, mas o backup em JSON guarda absolutamente tudo —
            inclusive categorias criadas por você e o que o app já aprendeu a categorizar sozinho.
          

          

            
            
          

          
        


        

          
Novo lançamento recorrente 

          

            Gastos ou receitas que se repetem todo mês (aluguel, assinaturas, salário) — o app lança
            sozinho no dia escolhido, sem você precisar lembrar.
          

          

        

      


      

        
Nuvem GitHub (Gist)

        

          Guarda o backup num Gist secreto da sua conta GitHub.
          Token: GitHub → Settings → Developer settings → Personal access tokens
          (clássico: permissão gist). Fica só neste aparelho.
